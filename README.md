ApplyTrack

A Java-based job application tracker that helps students and job seekers organize applications, monitor recruitment progress, and manage important dates.

Project Goal

Applying to multiple jobs and internships can make it difficult to keep track of application statuses, interview schedules, and follow-up dates. ApplyTrack aims to simplify this process by providing a centralized application management system through a simple command-line interface.

MVP Scope (Version 1.0)

The initial version of ApplyTrack will include:

Add Applications: Record company names, job titles, locations, application dates, and job links.

View Applications: Display all saved applications and their details.

Update Application Status: Track applications through Interested, Applied, Interview, Offer, and Rejected stages.

Save and Load Data: Store application records locally in a CSV file and load them when the program starts.

Search and Filter: Find applications by company name, job title, or application status.
